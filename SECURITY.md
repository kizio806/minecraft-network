# Security Policy

## Supported Versions

Security updates and vulnerability patches are actively maintained for the latest release on the default branch:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Minecraft Network and its infrastructure control plane seriously.

If you identify a security issue, vulnerability, or potential leak (including secret exposure, path traversal, authentication bypass, or DoS hazard):

1. **Do not create a public issue or discuss it publicly.**
2. Report the vulnerability through GitHub Private Vulnerability Reporting on this repository, or contact the project maintainers directly via private channels.
3. Include a description of the issue, affected components or files, and reproducible proof-of-concept steps.

## Response Process

- Maintainers will acknowledge your report within 48 hours.
- We will assess the impact, prepare a fix, and coordinate release notes before public disclosure.
