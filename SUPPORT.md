# Support Policy

Thank you for using **Minecraft Network**. This document outlines how to get assistance, report issues, and participate in community discussions.

---

## Getting Help

Before opening an issue, please consult the project documentation:
- [Architecture Overview](docs/architecture.md) — Topology, service layout, and network segmentation.
- [Development Guide](docs/development.md) — Local builds, testing, and debugging.
- [Deployment Guide](docs/deployment.md) — Production provisioning, environment variables, and Docker Compose.
- [Troubleshooting & Decisions](docs/decisions/README.md) — Architectural decision records (ADRs) explaining technical choices.
- [Discord Bot Guide](docs/discord-bot.md) — Bot setup, RCON integration, and moderation commands.

---

## Channel Guidelines

### 1. GitHub Issues
GitHub Issues are reserved for:
- **Bug Reports:** Reproducible defects in configuration, network orchestration, CLI, or Discord bot.
- **Feature Requests:** Concrete proposals with a clear use case and technical rationale.
- **Plugin Proposals:** Submissions following our declarative plugin supply chain specification.

Please use the appropriate [Issue Template](.github/ISSUE_TEMPLATE) when creating an issue.

### 2. Security Vulnerabilities
If you discover a security vulnerability or potential secret exposure, **do NOT open a public issue**. Follow the instructions in our [Security Policy](SECURITY.md) to report it privately.

### 3. Questions and General Discussions
For general questions regarding server configurations, hosting recommendations, or custom plugin integrations, open a thread in [GitHub Discussions](https://github.com/kizio806/minecraft-network/discussions) or reach out via our community Discord channels.

---

## Response Expectations

- **Triage:** Maintainers review new issues within 48–72 hours.
- **Bug Fixes:** Critical security and infrastructure issues are prioritized immediately.
- **Contributions:** Pull requests adhering to our [Contribution Guidelines](CONTRIBUTING.md) are warmly welcomed!
